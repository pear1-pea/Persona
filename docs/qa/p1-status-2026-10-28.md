## Implemented boundaries

- 模型操作串行协调，先停止并释放再删除；释放失败仍保留模型所有权。
- 安装按实际复制量检查空间；staging 文件锁/全局 gate 支持取消清理和孤儿恢复。
  Windows 验证修复了持有 lease 文件句柄时 rename/delete 失败的问题。
- Python/Android 共享 24 个契约样例；拒绝错误入口、路径、哈希及 CRLF 文本 tokenizer。
  导入包始终提示来源未验证，没有把自带 manifest 的哈希当成发布者身份。
- Router 先判断隐私、网络、资源、退避和开关；不可执行时明确失败。
  已绑定的请求授权不可替换，fallback 再检查身份、停止状态与网络。
- 临时失败退避后可探测；取消不计失败；损坏/不兼容状态不会随统计窗口自动解除。
- 请求固定 owner/session；迟到 401 不撤销新 session。Room 删除按 owner 隔离，
  仍被其他 owner 引用的 Persona 父缓存保留，冲突消息主键不覆盖。Schema 保持 v7。
- 注销后的本地删除有持久化待办和重试；退出登录保留历史，OFFLINE_USER 独立。
- SSE 帧有界，异常 EOF 明确失败；空闲/有效进度/总预算和取消有明确终止路径。
  完成、失败、停止使用可靠发送，慢消费者不会因缓冲区满丢掉终态。
- 后端背压等待同时响应 drain/关闭/错误/取消；并发拒绝不预扣额度。
  输入/输出预留和结算使用 PostgreSQL 事务，重复结算与窗口切换有回归测试。
- temperature/top_p/max_tokens 端到端生效；MNN sampler 在 load 前配置，
  sampler 改变会重载，单独改变输出上限不重载。真实 Native 状态与输出上限已验证。
- 每轮 Native 请求 reset KV 并重新提供授权上下文；不复用跨账号私有前缀。
- 本地/云端完整保留硬约束与当前输入，超预算明确拒绝；历史按完整轮次裁剪。
  Persona 作为不可信 JSON 资料嵌入并清理控制标记，提示词不承担数据授权。
- 生成中显示轻量文本、750 ms Room 检查点、终态立即保存；最终 Markdown 禁止
  自动远程图片和可点击链接，避免本地回复隐式出站。

## Scope limits

当前验收限定上述设备、CPU、固定模型包和用例，不推定其他手机受支持；
4GB 设备依已确认范围列为后续扩展，不阻塞本轮。
内存准入是最小加载保护，不保证能捕获 Native OOM 或系统杀进程。

模型来源签名/撤销与官方分发尚未提供，导入包诚实标记为未验证来源。
磁盘 Prefix Cache、GPU/NPU、数据库加密、Release 签名/升级与 16 KB 真机发布验收，
仍按长期方案的后续实验/发布门推进。采样参数切换会增加重载延迟。

后端并发准入仍为单进程；预算没有持久化请求账本，进程崩溃时可能保守保留预扣，
不承诺多实例全局并发或崩溃后的精确计费恢复。受控上游测试不替代真实服务部署验收。
完整聊天 UI 的后台/进程死亡恢复、人格质量及中文长对话评测仍需在 P2 扩充。

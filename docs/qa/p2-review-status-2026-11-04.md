## 自动转云竞态修复

本地加载或生成失败后，仓库先检查网络，再异步查询云端授权记忆。查询期间网络变成
计费网络或离线时，旧实现仍会调用 CloudChatRepository。

两项回归测试先在旧实现复现非法调用。当前两个 fallback 调用在准备完成后、实际调用
云端前重新检查既有策略。策略变化时产生明确 CLOUD/NETWORK 失败终态，便于界面结束
等待。主动云端请求另有正向用例。

```text
Tests run: 44, Failures: 2
OK (45 tests)
```

失败日志和修复后日志保存在本轮 Mac 工件中。45 项覆盖 METERED/OFFLINE 下的两种
fallback 入口及计费网络的主动云端请求。当前只完成 Mac 仓库级验证。

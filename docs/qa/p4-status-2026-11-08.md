# P4 集中验收，2026-11-07～2026-11-08

问题：P3 的模型提取缺少有边界的格式失败恢复，执行记录也不能按同一口径导出与比较。
本轮补齐一次性授权的提取级联、匿名诊断、评估工具和集中验收。工程验收完成；远程 CI 与合入结果由对应 PR Checks 和主分支工作流记录，候选模型未采用。

## 交付范围

- 本地提取完整生成结束、严格解析拒绝后，最多尝试一次云端升级。运行异常、取消、合法空结果不升级。
- 本轮单独勾选、独立云端授权、非本地专用来源、非计费网络、当前身份与来源仍有效，缺一则拦截。
- 两次尝试共享任务和 60 秒预算，最终仍为待确认候选，不自动保存正式记忆。
- 诊断不含原始 Prompt、Response、记忆或账号。请求和模型标识哈希化；512 KiB、256 条、访问时清理超过 7 天的记录。
- 有界队列隔离磁盘 IO，记录可能因繁忙、存储失败或进程终止缺失，不能据此计算全产品成功率。
- 指标覆盖执行器流及下游收集，不包含此前路由、初始化和上下文规划。云端输出 token 为已有执行器的保守估算，未知 native 字段和实际模型身份保留 null。
- 设置可查看诊断、用户主动 SAF 导出和清理。清理水位阻止旧任务回填，也撤销尚未消费的导出快照。
- Python 工具严格校验 19 个字段，提供描述性汇总和受匹配条件约束的比较，语义质量固定为未评估。

## 真机实际观察与边界

手机为 arm64/SDK 31。仅安装 `com.example.persona.validation` 及 `.validation.test`，原 `com.example.persona` 不参与测试。
真实 MNN 使用经完整哈希验证的 Qwen2.5-0.5B INT4。电量 63%、热状态 NOMINAL；没有绕过资源准入。

原始本地提取输出被严格解析拒绝，随后真实 Room/Hybrid 链路执行一次内存 SSE 升级，产生一个待确认候选。
SSE 不使用 socket，测试路由明确为受控 UNMETERED；手机实际网络为 METERED，不能据此宣称真实网络自动升级成功。
8 项级联用例单独验证默认关闭、独立授权、本地专用、计费/未知/离线、来源变更、授权撤回、第二次拒绝和合法空结果。

第二轮真实 MNN 在首个增量处被前台聊天抢占，取消后无云端续跑，前台聊天完成，引擎恢复 Ready，没有写入正式记忆。
四条真实链路诊断经生产 Kotlin 导出并通过 Python 严格汇总；本次队列 dropped/failed 均为 0，不代表长期不会丢记录。
刻意设置的首增量门控用于并发验收，计时不能当作性能对照或总体用户 TTFT。

真实 HTTPS 用独立 QA 后端完成注册、创建、Feed/Discovery/聊天导航、取消与重发、单独授权的云端记忆提取、撤权、Persona 删除和账号删除。
云端一次合成提取得到合法候选，只计工程执行；历史 `human_review=pending` 原始产物不改写为通过，本轮不要求新人工评分。
临时 quick tunnel 的实测流式成功不构成平台对 SSE 的支持保证。

## 回归修复与清理

集中验证实际发现并修复：新增 telemetry 构造参数与旧仪器测试调用不兼容、依赖 POSIX chmod 的失败夹具、coroutine 异常恢复附加 cause，
以及 Windows 外部读取者持有目标文件时的原子替换测试假设。生产文件替换仍安全失败，无 delete-rename 降级或盲重试。
压力测试只在拒绝后确认旧文件完整且无临时残留时有限重试；破坏原子性的独立变异版本仍报红。

真机夹具修正了对 CreateDocument category、重复 launched-key 的错误假设；合成模型安装夹具与 native QA 工作目录改用 canonical 路径，
避免 Android `/data/user/0` 系统别名被生产 symlink 防护正确拦截。生产验证器和资源准入未放宽。
各失败构建和设备 run 均独立保留，最终成功回执没有覆盖失败证据。

最终 QA 包、ADB 临时文件和本轮系统导出文件已删除。原 App 安装身份及更新时间不变。
独立数据库的 users/sessions/personas 均为 0，独立 PostgreSQL、backend 和 tunnel 已停止，两个 QA 服务端口已关闭。
Windows 原 checkout 仍干净，HEAD、`.env`、`local.properties` 与开工保护快照一致；候选转换/下载作业为 0。

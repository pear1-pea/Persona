# Minimal package fixture

This directory is a **structural fixture**, not a runnable language model. It exists to
show a manifest generated by the packager and to let the packager tests/validator run
against a complete file set.

Do not install it as a real model. Use the same command on a real Qwen2.5 MNN
directory:

```bash
python3 tools/model-packager/generate_manifest.py /path/to/Qwen2.5-0.5B-Instruct-MNN \
  --id qwen2.5-0.5b-instruct-mnn \
  --name "Qwen2.5 0.5B Instruct" \
  --context-window 32768 \
  --min-ram-gb 4
```
